## 页面说明

### 主页面 (index.html)
- 网站首页，展示四大专题模块概览
- 包含导航栏、横幅和模块卡片

### 模块一：丝弦溯古 (module1)
- **百年文脉** (page1.html)：追溯南曲起源与发展脉络
- **雅韵特质** (page2.html)：解析南曲艺术特色与乐器
- **文化密码** (page3.html)：深挖土家族文化内涵

### 模块二：现代弦歌 (module2)
- **匠人守艺** (page1.html)：传承人故事与坚守精神
- **文旅共生** (page2.html)：南曲与旅游的融合发展
- **薪火相传** (page3.html)：南曲进校园的实践与成果

### 模块三：雅韵思辨 (module3)
- **政策解读** (page1.html)：国家及地方非遗保护政策
- **数据透视** (page2.html)：基于调研数据的现状分析
- **民间心声** (page3.html)：不同群体的真实观点

### 模块四：弦音互动 (module4)
- **曲段学唱** (page1.html)：零基础学唱南曲
- **非遗打卡** (page2.html)：参与"寻找身边的南曲"活动
- **在线问答** (page3.html)：知识测验与互动留言板

## 使用方法

1. 直接在浏览器中打开 `南曲/index.html` 即可访问主页面
2. 通过导航或模块卡片进入各个子模块
3. 每个模块都有返回按钮，方便导航
